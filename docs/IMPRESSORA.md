# Impressora para crachás

O sistema imprime pelo diálogo de impressão do navegador (CSS de impressão, tamanho configurável em **Configurações → Crachás**). Qualquer impressora com driver para o computador/tablet da recepção funciona; para crachá com QR Code, **impressora térmica de etiquetas** é a melhor escolha (rápida, sem tinta, etiqueta adesiva).

## Recomendação
**Brother QL-820NWB** (etiquetas de 62 mm, USB + Wi-Fi + Ethernet + Bluetooth)
- Dá para ligar na rede e imprimir de qualquer computador da recepção; tem suporte a AirPrint (iPad).
- Etiquetas: rolo contínuo **DK-22205** (62 mm) ou pré-cortadas **DK-11202** (62×100 mm — boa para crachá).
- Configuração no sistema para DK-11202: largura **100 mm**, altura **62 mm**.

Alternativas
- **Brother QL-800** (mesma qualidade, só USB, mais barata) — se for um único computador fixo.
- **Zebra ZD421/ZD220** (etiqueta 4") — mais robusta para alto volume; exige papel/rolo Zebra.
- **Dymo LabelWriter 550** — funciona, mas só aceita etiquetas Dymo com chip (custo recorrente maior).

## Dicas de uso
1. Instale o driver oficial no computador e, no diálogo de impressão do navegador, escolha o tamanho de papel igual ao da etiqueta, margens "nenhuma" e escala 100%.
2. Faça um teste de leitura do QR com a tela **Crachás → Ler QR Code** antes de imprimir em lote.
3. Para pulseira/crachá reutilizável, imprima em cartão PVC com impressora de cartões (só se o volume justificar).
4. No app Flutter futuro, a impressão direta pode usar o SDK da Brother (Bluetooth/Wi-Fi), sem diálogo.

Confira preços e disponibilidade locais antes de comprar.
